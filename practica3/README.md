# Practico 3 - Agenda de turnos

Proyecto Java pequeno para practicar controles de calidad.

## Que hace

- Reserva un horario para un paciente.
- Impide dos reservas en el mismo horario.
- Permite cancelar un turno solo al paciente que lo reservo.
- Rechaza nombres vacios.

## Ejecutar las pruebas

Se necesita JDK 17 y Maven. Desde la raiz del repositorio:

```sh
mvn -f practica3/pom.xml test
```

La configuracion del hook, el analisis estatico y las evidencias del informe final se agregaran en pasos posteriores. Este archivo no afirma que las pruebas ya hayan sido ejecutadas.
